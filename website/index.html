Smart and open source

Record and track your grip strength training, all built on open source hard and software.

Ongoing development

This project is still under development. Please Check out the github repository for the latest progress

The grip board

The hardware for the grip board can be fully 3d-printed. It uses a load cell and an ESP32 based microcontroller for recording the weight readings. Basic crimping or soldering skills are required to build the electronics part of the hardware.
